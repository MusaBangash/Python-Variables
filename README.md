# Python Mastery — visual slide lessons

Animated, video-style slide lessons for learning Python, built with [reveal.js](https://revealjs.com).

**Live site:** https://musabangash.github.io/Python-Variables/

| Module | Topic | Link |
|---|---|---|
| 3 | References, Mutability & Memory | [module3.html](https://musabangash.github.io/Python-Variables/module3.html) |

## Controls
- **← / →** or swipe: move between slides
- **N**: show/hide the presenter line for each slide
- **F**: fullscreen

Each deck is a single HTML file. Open it in any browser; no install needed.
