ML Bootcamp · 2 days · 16 hours

Machine learning from zero to a working model

This handbook assumes you know nothing about machine learning. Read it from top to bottom and you will understand what ML is, how every step of a real project works, how five important models work inside, and how to build, test, save and share a model yourself.

How to use this handbook

  • Read the parts in order. Each part uses ideas from the part before it.
  • Every concept is explained three ways:

A simple explanation with an everyday example. Read this first.

The real explanation: the details, the maths in plain words, and the reasons behind it.

A mistake beginners (and professionals) often make, and how to avoid it.

A question or small task. Stop and do it before reading on.

  • Practicals are step-by-step. Every step says what we do, why we do it, and shows the code and the result. Each practical also opens as a ready-to-run notebook in Google Colab (free, runs in your browser, nothing to install).
  • If a word is new, look it up in the Glossary.

What you will learn

By the end of the two days you should be able to tick every box below. Use it as a checklist.

Concepts - [ ] Explain what machine learning is, and when it is (and is not) the right tool - [ ] Tell supervised from unsupervised learning, and regression from classification - [ ] Explain overfitting and underfitting, and why we keep a test set - [ ] Explain data leakage and how to prevent it - [ ] Explain how linear regression, logistic regression, decision trees, random forests and k-means work inside

Practical skills - [ ] Load a dataset and check it: types, missing values, duplicates, ranges, target balance - [ ] Split data into training and test sets correctly - [ ] Prepare numbers (fill gaps, scale) and categories (one-hot encoding) inside a pipeline - [ ] Train a baseline and at least two real models, and compare them fairly with cross-validation - [ ] Choose and explain the right metric: MAE, RMSE, R², accuracy, precision, recall, F1 - [ ] Read a confusion matrix and residuals, and explain what the errors mean - [ ] Improve a model with feature engineering and hyperparameter tuning - [ ] Find groups in data with k-means and describe them carefully - [ ] Save a model, load it in a new session, and predict on new rows - [ ] Write a model card describing intended use, limits and risks - [ ] Put your model behind a simple Streamlit app
