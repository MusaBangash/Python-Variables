Glossary and frequently asked questions

Term Meaning
Accuracy share of predictions that are correct; misleading when one class is rare
Algorithm the learning procedure (e.g. least squares, CART)
AUC (ROC AUC) chance that a random positive gets a higher score than a random negative; 0.5 = random, 1 = perfect
Bagging training many models on random bootstrap samples and averaging them
Baseline the score of the simplest possible approach; every model must beat it
Batch inference predicting for a whole file at once, on a schedule
Bias (fairness) systematic unfairness towards some group, often learned from the data
Bias (intercept) the constant term b in a linear model
Boosting training models one after another, each fixing the previous mistakes
Bootstrap sample a random sample with replacement
Calibration whether predicted probabilities match real frequencies
CART the greedy algorithm that grows decision trees
Categorical feature a feature whose values are categories (nominal or ordinal)
Centroid the centre (mean point) of a cluster in k-means
Classification predicting a category
Clustering grouping similar examples without labels
Concept drift the relationship between inputs and the answer changes over time
Confusion matrix table of true/false positives/negatives
Correlation how strongly two numbers move together in a straight line (−1 to 1)
Cross-validation (k-fold) split training data into k parts; train on k−1, score on 1; rotate; average
Data drift new input data looks different from training data
Data leakage the model sees information during training that it won't have when used for real
DataFrame a pandas table
Decision boundary where a classifier switches from one class to another
Decision tree a model that predicts by asking a series of yes/no questions
Deep learning machine learning with many-layer neural networks
Early stopping stop training when validation error stops improving
Embedding a list of numbers representing an item (e.g. text) so that similar items are close
Ensemble a group of models whose predictions are combined
Entropy an impurity measure from information theory
Epoch one pass over all training data (gradient descent)
F1 score balance (harmonic mean) of precision and recall
False negative (FN) a real positive predicted as negative (missed)
False positive (FP) a real negative predicted as positive (false alarm)
Feature an input column used to predict
Feature engineering creating new useful features from existing ones
Feature importance how much a model relies on each feature
Fit learn from data (model.fit(X, y))
Gini impurity chance two random items in a box belong to different classes
Gradient the direction and steepness in which the error increases
Gradient descent repeatedly step the parameters downhill on the error
GridSearchCV try every listed combination of hyperparameters with cross-validation
Hyperparameter a setting you choose before training (depth, alpha, learning rate)
Imputation filling missing values
Inertia total squared distance from points to their k-means centres
Inference using a trained model to predict
Intercept see bias (intercept)
k-means clustering by repeatedly assigning points to the nearest centre and moving the centres
Label / target the answer the model learns to predict
Lasso regularisation that can shrink useless weights to zero (L1)
Learning rate step size in gradient descent / boosting
Linear regression predicts a number as a weighted sum of features
Log loss (cross-entropy) classification loss that punishes confident wrong predictions
Logistic regression linear score squeezed by the sigmoid into a probability
MAE / MSE / RMSE average absolute / squared / root-squared error
Model what you get after training: a function with learned parameters
Model card short document describing a model's use, performance, limits and risks
One-hot encoding one 0/1 column per category
Out-of-bag (OOB) scoring each row with the trees that didn't see it: free validation in bagging
Overfitting memorising training data; poor on new data
Parameter a number learned during training (weights)
PCA finds the directions of greatest spread to reduce dimensions
Permutation importance score drop when one feature is shuffled
Pipeline preprocessing steps + model chained into one object
Precision of the predicted positives, the share that are right
PSI population stability index: a drift measure
R² share of variation explained; 0 = as good as the mean, 1 = perfect
Random forest bagging of decision trees with random feature subsets
RandomizedSearchCV try a random sample of hyperparameter combinations with cross-validation
Recall of the real positives, the share we found
Regression predicting a number
Regularisation penalising complexity to reduce overfitting
Reinforcement learning learning by trial, error and rewards
Residual actual minus predicted
Ridge regularisation that shrinks all weights (L2)
Scaling putting numeric features on a similar scale (e.g. StandardScaler)
Schema the expected columns, types and value ranges of input data
Self-supervised learning the data provides its own labels (e.g. predict the next word)
Sigmoid S-shaped function turning any number into 0–1
Silhouette score how well separated clusters are (−1 to 1)
Softmax turns several scores into probabilities that add up to 1
Stratified split split that keeps class proportions equal
Supervised learning learning from examples with answers
Test set data held back and used once for the final honest score
Threshold probability above which a classifier says "positive"
Training set data the model learns from
Transformer (scikit-learn) an object with fit and transform (scaler, encoder, imputer)
Underfitting model too simple to capture the pattern
Unsupervised learning finding structure without answers
Validation set data used to choose models and settings
Weight a learned multiplier for a feature

Frequently asked questions

Do I need a GPU for this bootcamp?No. Every practical runs in seconds to a few minutes on a normal laptop or free Colab.
Which model should I learn first?Linear and logistic regression: they teach loss functions, gradient descent and evaluation that every other model uses.
Why do my numbers differ slightly from the handbook?Different library versions or random seeds. Small differences (third decimal) are normal; big ones mean a step differs.
How do I know if my model is good enough?Compare with the baseline and with a simple model, using cross-validation, and translate the result into the business decision (money, risk, workload).
What should I learn after this bootcamp?Gradient boosting libraries (XGBoost, LightGBM), SHAP for explanations, then neural networks (PyTorch), and from there transformers and LLMs.
