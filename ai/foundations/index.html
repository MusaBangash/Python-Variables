How LLMs really work, built step by step

Before building with large language models (RAG, tools, MCP, agents), you will understand what an LLM actually is, by building every piece yourself, from a single neuron to a small GPT that writes text.

Part Topic You will build
1 Neural networks a neuron by hand, a network trained from scratch (NumPy), then PyTorch and a handwritten-digit reader
2 Text as numbers: tokens, embeddings, next-token prediction a tokenizer and a small language model that writes text
3 Attention and the Transformer self-attention by hand, then a tiny GPT trained on text
4 From tiny GPT to real LLMs inspect a real pretrained model: tokens, probabilities, temperature
5 LLMs for builders API calls, cost, a chatbot with memory

After the foundations: RAG → tool use → MCP → agents → evaluation → deployment.

Each part has the same layout: a simple explanation ("Like I'm 10"), the real explanation ("Going deeper"), common mistakes, questions to think about, and a step-by-step practical that runs in Google Colab, shown here with its real outputs.

You need: basic Python, a Google account for Colab. No GPU needed for the foundations.
